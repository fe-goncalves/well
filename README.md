# WELL

Web **mobile-first** de hábitos: alimentação com IA, movimento, diário e metas.

Docs: [`docs/PLAN.md`](./docs/PLAN.md) · [`docs/BUSINESS_RULES.md`](./docs/BUSINESS_RULES.md) · [`docs/UI_UX.md`](./docs/UI_UX.md)

## Stack

- Next.js + TypeScript + Tailwind
- Supabase · Gemini API

## Desenvolvimento

```bash
npm install
cp .env.example .env.local
npm run dev
```

> Se `node` falhar com OpenSSL: `$env:OPENSSL_CONF = $null`
